Лабораторна робота 6: Мінімальний кістяк графа (MST)
Варіант: 5515  |  n = 11 вершин  |  Алгоритм Пріма
Коефіцієнт k = 1.0 - 0.01*1 - 0.005*5 - 0.05 = 0.915
====================================================================

Ця лабораторна робота реалізує пошук мінімального кістякового дерева за допомогою жадібного алгоритму Пріма. 
Для зручності демонстрації, алгоритм реалізовано у кількох варіантах: як десктопна програма та як автономні веб-сторінки.

### 📁 Структура файлів:

* **`lab6_main.py`** — оригінальна програма на Python. Використовує `tkinter` для графічного інтерфейсу та вбудовану чергу з пріоритетом (`heapq`) для швидкої роботи алгоритму.

* **`lab6.html`** (та копія **`index.html`**) — повноцінна веб-версія на чистому JavaScript та HTML5 Canvas. Відкривається просто в браузері, має власну реалізацію структури Min-Heap для оптимізації складності.

* **`lab6_2.html`** — максимально спрощена веб-версія на JS. Код скорочено до ~100 рядків, прибрано складну математику та класи. Ідеально підходить для швидкого пояснення базової логіки викладачу.

* **`index.html`** — головний файл програми. Це повноцінна веб-версія, написана на чистому JavaScript з використанням HTML5 Canvas. Вона містить математичну логіку генерації графа, сам алгоритм Пріма (реалізований через генератори для покроковості) та інтерфейс відмальовки. Працює автономно — достатньо просто відкрити файл у будь-якому браузері.
